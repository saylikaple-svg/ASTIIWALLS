# 🛹 AstiWalls by webxy // 4K Wallpapers for Mobile & Laptop

A modern, high-contrast 4K wallpaper platform for Mobile phones (9:16) and Laptops (16:9) with Google authentication, interactive hardware device previews, community upload studio with AI safety moderation, and curated collections.

---

## ✨ Features

- **📱 Mobile (9:16) & 💻 Laptop (16:9) Drops**: Curated 4K & Retina wallpapers across Synthwave, Cyberpunk, 90s Retro, Pixel Art, Nature, and Minimal.
- **📱 Live Hardware Previews**: Interactive iPhone 15/16 Pro Max lockscreens and MacBook desktop mockups.
- **🔑 Google Sign-In (Firebase Console)**: 1-click Google authentication with real Firebase project support.
- **🔒 Login-Gated 4K Downloads**: Free live exploration and device testing, with 1-click 4K downloads unlocked upon login.
- **📤 Upload Studio with AI Safety**: Community upload portal featuring automatic aspect ratio detection, color palette extraction, and computer-vision adult content/NSFW filtering.
- **❤️ Favorites & Profiles**: Save favorite collections and manage your uploaded wallpapers.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/saylikaple-svg/ASTIIWALLS.git
cd ASTIIWALLS
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Firebase Configuration (Optional)
Copy `.env.example` to `.env` and fill in your Firebase Console credentials:
```bash
cp .env.example .env
```

### 4. Run development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
